# Corrections

## Policy

BreachBook corrects errors openly. When a published fact is found to be wrong — whether reported by a
reader, surfaced by a source update, or caught internally — the record is corrected, the correction is
logged here with the date and exactly what changed, and the affected record is marked `corrected`. Records
are never silently edited and never deleted; a record shown to be unfounded is marked `retracted` with the
retraction logged here.

## How to report an error

Open an issue in the project repository:
[report a correction](https://github.com/kevynsgrin-a11y/BreachLedger/issues/new). Include the URL of the
page and, where you have one, a citation to the government or court document that shows the correct fact.
Reports carrying a citation are actioned fastest, because a citation is the standard the correction itself
has to meet.

Filing an issue currently requires a GitHub account. A dedicated correspondence address is not yet in
service; when one is, it will be published here and a GitHub account will stop being necessary. Until then,
a report that cannot be filed as an issue can be raised through any of the project contacts listed on the
[sources page](/sources/).

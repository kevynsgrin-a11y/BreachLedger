# Corrections

## Policy

BreachBook corrects errors openly. When a published fact is found to be wrong — whether reported by a
reader, surfaced by a source update, or caught internally — the record is corrected, the correction is
logged here with the date and exactly what changed, and the affected record is marked `corrected`. Records
are never silently edited and never deleted; a record shown to be unfounded is marked `retracted` with the
retraction logged here.

## How to report an error

Write to **corrections@breachbook.org**. Include the URL of the page and, where you have one, a citation to
the government or court document that shows the correct fact. Reports carrying a citation are actioned
fastest, because a citation is the standard the correction itself has to meet.

Readers who would rather file in the open can instead
[open an issue](https://github.com/kevynsgrin-a11y/BreachLedger/issues/new) in the project repository; that
route requires a GitHub account, which the email address does not.
